# TD Terraform

Ce dossier regroupe les livrables Terraform demandés.

## Dossiers

- `foundation-gcp/` : IaC GCP (VPC, VM, SQL, DNS)
- `foundation-aws/` : IaC AWS (VPC, EC2, RDS, DNS)

## Commandes

Dans chaque dossier :
```bash
terraform init
terraform validate
terraform plan
```

- GCP : voir `foundation-gcp/README.md`
- AWS : voir `foundation-aws/README.md`
